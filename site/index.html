01 / Sessions

The backend of an agentic CLI

One session, one primary verb, a stream of events back. Answer, steer or abort while the agent works. Every step lands in the journal before it takes effect.

Prompt goes in, a live event stream comes out, tools fire under permission policy. Everything is journaled.

Seven concepts

There is no job type. A headless run is a session with options.

Agent

Model config, system prompt, tools, skills, sub-agents, permission defaults, package source.

Session CORE

A conversation with one agent: tenant, state, transcript, inbox, workspace. Lives until closed or expired.

UserMessage

Text, file or image parts. The only thing that starts a turn, journaled before it is acted on.

Reply

The host answering a permission or a question. Resumes a suspended turn, never starts one.

Turn CORE

One ReAct run. Ends on stop, abort or budget; suspends on reply. The unit of lease and claim.

SessionEvent

The fine-grained ordered journal: TurnStarted, TextDelta, ToolCallStarted, TurnCompleted.

SessionCell

The coarse transcript, derived from events for replay and UI.

Legate.Abstractions

All seven live in one package that depends on nothing else in the solution.
