The mental model

Think of the backend of an agentic CLI: a session, one primary verb (send a message), a stream of events back, and the power to answer, steer, or abort while the agent works.

Prompt goes in, a live event stream comes out, tools fire under permission policy. Everything is journaled.

Seven concepts, no more

The whole model fits on an index card. There is deliberately no job type: a headless run is just a session with options.

Agent

A definition: model config, system prompt, tools, skills, sub-agents, permission defaults, package source.

Sessioncore

A conversation with one agent. Id, tenant, title, state, transcript, inbox, workspace binding. Lives until closed or expired.

UserMessage

Text, file, or image parts. The only thing that starts a turn, journaled before it is acted on.

Reply

The host answering a permission or a question. Resumes a suspended turn, never starts one.

Turncore

One ReAct run. Ends on stop, abort, or budget; suspends on reply. The lease and claim unit.

SessionEvent

Fine-grained ordered journal: TurnStarted, TextDelta, ToolCallStarted, TurnCompleted. Hosts render these.

SessionCell

The coarse transcript (user, assistant, tool call/result, system), derived from events for replay and UI.

A turn, step by step

Watch one prompt travel through the runtime. The highlight advances on its own.

1
Prompt lands in the inbox.

The message is appended to ISessionStore and the dispatcher wakes the session entity (sharded in cluster mode, a local child actor otherwise).

2
The turn is claimed under a lease.

Exactly one owner wins. Every later side effect re-checks the opaque claim token at the last moment.

3
Workspace, agent, model.

The workspace binds, the agent package loads (AGENTS.md, skills), and a rate-limited IChatClient is built.

4
Tools assemble.

Built-ins (file, exec, skill, task, ask_user), custom HTTP tools, every IToolSource. Each call passes IPermissionPolicy.

5
The ReAct loop runs.

Events flow to the journal and live subscribers; injected messages fold in at iteration boundaries.

6
Settle and rest.

Usage checkpoints, the turn settles, the session returns to Idle or waits for input. Headless sessions close via the completion sink.

Two first-class hosts

CLI harness

One process, no database server. Tools act on your working directory, approvals pop mid-turn, SQLite holds the journal. Samples: LegateCli, MinimalHost.

Hosted service

Many tenants, clustered nodes, Postgres plus S3, sandboxed workspaces, headless sessions with webhooks. Samples: CSharpHost, Headless, cluster-compose.
