02 / Durability deep dive

One owner, one journal, zero doubles

The overview shows the kill. This page shows the machinery underneath: atomic claims, a gap-free event journal with cursor replay, and the cluster that survives the kill.

Fencing

The token is the authority

ClaimNextTurn hands a turn to exactly one caller. Checkpoint, settle, abort, tool calls, and journal writes verify the opaque token store-side at the last moment. A stale token returns lost or rejected instead of acting.

Inbox append, claim, renew, checkpoint, settle: each lands in one transaction. Readers never see a half-applied step.
Journal

Replayable by cursor

The event journal is the audit trail and the source of Subscribe. Batches append under the turn claim token; the store stamps gap-free 1-based sequences, and a stale token rejects the whole batch with zero writes.

Cursor replay

Bounded pages by exclusive int64 cursor: page with NextCursor, end of stream, unknown session, expired journal. Subscribers resume exactly where they left off.

Bounded by config

Per-event bytes, per-session count and bytes, batch size. A breach throws EventLimitExceededException before any part of the batch lands.

Janitor with a lease

Journal cleanup is itself claimed (TryClaimCleanup, CompleteCleanup, DeferCleanup), so retention never races a live tail.

The saga

Four issues, one green smoke

Each layer of the crash-resume proof exposed the next, and each shipped with its own tests. The animated loop on the overview is this story compressed.

Marker (#284)A fenced TurnStartedEvent journaled at provider-call entry: the deterministic in-call signal no production path previously emitted.
Tail recovery (#287)Entity start routes Idle-with-live-turn plus unterminated-tail rows through journal-tail recovery under the fresh primed claim.
Completion era (#289)One terminal event per settled turn, an era gate for old marker-only histories, and a dispatcher sweep that re-pokes and settles directly when survivors go quiet.
Seeded smoke (#271)Stable smoke agent, open-with-agent-id, short-lease overlay, SIGKILL mid-call. Green in CI: Fail per policy, frames 1..2 gap-free and duplicate-free.
Cluster

Same logic, sharded

Actor logic is shared between single-node and clustered mode; translation happens at the serialization boundary. The bar: core builds and tests with no external services.

Runtime

StaticSeeds joins named seeds and shards entities by session id; Kubernetes bootstraps via Akka.Management plus discovery. Keep-majority split-brain, readiness gates, graceful drain.

Event bus

Cross-node Subscribe through the owning entity with a bounded replay cache. Node A tails a session on node B and resumes gap-free from its cursor after a real restart.

Wire format

Token-less DTOs under versioned legate.*.v1 envelopes with golden files. Current and current-minus-one accepted; everything else fails closed.

Redis admission

Two processes on one Redis respect one combined LLM limit: FIFO waiters with TTL, owner-fenced leases, fail policies, a startup canary gating readiness.
