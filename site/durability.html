Page 2: durability

Kill a node mid-sentence. The turn survives.

Every turn runs under a lease with an opaque claim token. Every side effect re-checks that token at the last moment, every event lands in a gap-free journal, and on restart the session replays and resumes or fails cleanly. A correlation id is evidence, never authority.

Fencing: one owner, zero doubles

ClaimNextTurn hands a turn to exactly one caller. Checkpoint, settle, abort, tool calls, and journal writes all verify the token store-side. A stale token returns lost or rejected instead of acting.

The atomic claim admits one owner. Every later write carries the token; losers observe rejection, never a double claim.

Atomicity

Inbox append, claim, renew, checkpoint, settle: each lands in one transaction. Readers never see a half-applied step.

Result objects

Lease states and settlements are values callers branch on, with stable wire discriminators. Only control-plane misuse throws.

Tenancy

Every store call carries a TenantId. Isolation is enforced in the stores, not just the host.

The crash-resume saga, live in CI

The three-node compose harness opens a session, waits for the journaled TurnStartedEvent, SIGKILLs the executing node mid-LLM-call, and demands the turn settle with no duplicated side effects and no subscriber gap. Watch the loop.

The kill flashes, the survivor settles. Marker, completion, and predicate all key on one fenced turn id.

Clustered when you want it

Same actor logic in single-node and clustered mode. The test-suite bar: Legate builds and tests with no Redis, Docker, Postgres, or Kubernetes.

Runtime

StaticSeeds joins named seeds and shards entities by session id; Kubernetes bootstraps via Akka.Management plus discovery. Keep-majority split-brain resolution, readiness gates (self Up, session role, zero unreachable, strict majority), graceful drain against live turn counts.

Event bus

Cross-node Subscribe routes through the owning entity with a bounded replay cache. A subscriber on node A tails a session on node B and resumes gap-free from its cursor after a real restart. At-least-once, always.

Wire format

Every cross-node message is a token-less DTO under a versioned legate.*.v1 envelope with golden files. Readers accept current and current-minus-one; anything else fails closed before deserializing.

Redis admission

Two processes on one Redis respect one combined LLM concurrency limit: FIFO waiters with TTL, owner-fenced leases, fail-closed or bounded fail-open, a startup canary gating readiness.
