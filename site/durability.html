02 / Durability

Kill a node mid-sentence. The turn survives.

Every turn runs under a lease with an opaque claim token, rechecked before each side effect. CI runs this on three nodes: SIGKILL the owner during an LLM call and the turn settles with no duplicates and no subscriber gap.

ClaimNextTurn admits exactly one owner. A stale token is rejected, never obeyed. A correlation id is evidence, never authority.

Fenced claims

Checkpoint, settle, abort, tool calls, journal writes: every side effect verifies the token store-side at the last moment.

One transaction per step

Inbox append, claim, renew, checkpoint and settle are atomic. Readers never see half a step.

Tenancy in the store

Every store call carries a TenantId. Isolation is enforced below the host.

The saga

Four issues, one green smoke

Each layer of the crash-resume proof exposed the next, and each shipped with its own tests. This is the loop above, frame by frame.

Marker (#284)A fenced TurnStartedEvent journaled at provider-call entry: the deterministic in-call signal no production path previously emitted.
Tail recovery (#287)Entity start routes Idle-with-live-turn plus unterminated-tail rows through journal-tail recovery under the fresh primed claim.
Completion era (#289)One terminal event per settled turn, an era gate for old marker-only histories, and a dispatcher sweep that re-pokes and settles directly when survivors go quiet.
Seeded smoke (#271)Stable smoke agent, open-with-agent-id, short-lease overlay, SIGKILL mid-call. Green in CI: Fail per policy, frames 1..2 gap-free and duplicate-free.
Cluster

Clustered when you want it

Same actor logic in single-node and clustered mode. The bar: Legate builds and tests with no Redis, Docker, Postgres, or Kubernetes.

Runtime

StaticSeeds joins named seeds and shards entities by session id; Kubernetes bootstraps via Akka.Management plus discovery. Keep-majority split-brain, readiness gates, graceful drain.

Event bus

Cross-node Subscribe through the owning entity with a bounded replay cache. Node A tails a session on node B and resumes gap-free from its cursor after a real restart.

Wire format

Token-less DTOs under versioned legate.*.v1 envelopes with golden files. Current and current-minus-one accepted; everything else fails closed.

Redis admission

Two processes on one Redis respect one combined LLM limit: FIFO waiters with TTL, owner-fenced leases, fail policies, a startup canary gating readiness.
