Host hooks

Six seams, nothing else

Host hooks are the only places a host's business rules enter the runtime. Legate reports tokens; it never prices them.

HookWhat the host decides
ISessionAdmissionPolicyWhether a session may start or prompt at all
IUsageObserverWhat to record about token usage per turn
IModelPolicyWhich model serves which call
IToolSourceWhere custom tools come from (MCP servers plug in here)
IPermissionPolicyWhich tool calls need approval, and from whom
IWorkspaceRuntimeWhere tools act: host directory, Docker sandbox, or scratch
