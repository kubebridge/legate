References point inward. Hosts plug in at the edges.

Everything depends on Legate.Abstractions, which depends on nothing in the solution. Stores, workspaces, LLM providers, and tools are interfaces with defaults. Your business rules enter only through host hooks.

Hello, session

The C#-friendly surface: Tasks, never Async; XML docs on every public member.

// Program.cs: register once
services.AddLegate(options => {
    options.UsePostgres(postgresConnectionString);
    options.AddOpenAIProvider(openAiKey, "gpt-4o-mini");
    options.AddMcpServer("docs", transport);
});

// Anywhere: open, prompt, stream, steer
var session = await client.OpenSessionAsync(agentId, tenant);
await client.PromptAsync(session.Id, userMessage, DeliveryMode.Queue);
await foreach (var e in client.SubscribeAsync(session.Id, fromSequence: 0)) {
    renderer.Render(e); // TurnStarted, TextDelta, ToolCallStarted ...
}
await client.ReplyAsync(session.Id, permissionDecision); // resume, never start

The package map

Sixteen packages, one rule: inward references only. Abstractions never touches Akka.

Legate.Abstractions

Contracts: domain types, store, tool, workspace, policy interfaces. Deps: FSharp.Core plus AI abstractions only.

Legateruntime

Actors, dispatcher, ReAct loop, built-ins, LLM coordinator, hosted services, AddLegate.

Legate.Llm.*

OpenAI plus compatible endpoints, Ollama Cloud, Gemini via Google.GenAI.

Storage

Postgres, SQLite, InMemory, S3, FileSystem, plus shared FluentMigrator migrations with an additive-only rule.

Coordination.Redis

Distributed LLM admission over Redis: one combined limit across processes.

Workspace.*

Docker CLI, host directory, or scratch process workspaces behind one runtime interface.

Cluster.Kubernetes

Akka.Management plus Kubernetes discovery bootstrap with sample manifests and a k3d runbook.

Mcp / Testing

ModelContextProtocol tool sources; fakes, clock seams, and scripted chat clients for tests.

Pick a store, keep the contract

Postgres, SQLite, and InMemory implement the same ISessionStore plus ISessionEventStore, pinned by shared conformance suites.
