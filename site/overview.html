Seven concepts

There is no job type. A headless run is a session with options.
AgentModel config, system prompt, tools, skills, sub-agents, permission defaults, package source.
SessionCOREA conversation with one agent: tenant, state, transcript, inbox, workspace. Lives until closed or expired.
UserMessageText, file or image parts. The only thing that starts a turn, journaled before it is acted on.
ReplyThe host answering a permission or a question. Resumes a suspended turn, never starts one.
TurnCOREOne ReAct run. Ends on stop, abort or budget; suspends on reply. The unit of lease and claim.
SessionEventThe fine-grained ordered journal: TurnStarted, TextDelta, ToolCallStarted, TurnCompleted.
SessionCellThe coarse transcript, derived from events for replay and UI.
Legate.AbstractionsAll seven live in one package that depends on nothing else in the solution.

02 / Durability

Kill a node mid-sentence. The turn survives.

Every turn runs under a lease with an opaque claim token, rechecked before each side effect. CI runs this on three nodes: SIGKILL the owner during an LLM call and the turn settles with no duplicates and no subscriber gap.

One transaction per stepInbox append, claim, renew, checkpoint and settle are atomic. Readers never see half a step.
